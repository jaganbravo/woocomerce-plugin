# How to Play Pirate Fighter

## Quick Start

The game is available in two formats:

### Option 1: Web Version (Play Now!)

1. Open `index.html` in your web browser
   - Double-click the file, or
   - Right-click → Open With → Your Browser
   - Or drag and drop `index.html` into your browser window

2. The game will load immediately - no installation needed!

### Option 2: Godot Version (Full Features)

1. Download and install Godot Engine 4.2+ from https://godotengine.org
2. Open Godot and click "Import"
3. Navigate to this folder and select `project.godot`
4. Click the Play button (F5) to run

## Controls

- **A** or **Left Arrow**: Move left
- **D** or **Right Arrow**: Move right  
- **Space** or **W**: Jump
- **X**: Basic attack
- **Z**: Special attack

## Gameplay

1. Select your pirate character from 10 available options
2. Each character has unique stats (health, speed, attack power)
3. Fight 3 enemy types (Pirate, Skeleton, Captain)
4. Defeat all enemies to win!

## Web Version Features

- All 10 playable characters
- Full combat system
- Enemy AI
- Health system
- Character selection screen

Enjoy the game!
